# Roll-a-Ball

A Unity game based on Unity's official [Roll-a-Ball tutorial](https://learn.unity.com/course/roll-a-ball).

## About

This project was built by following Unity Learn's Roll-a-Ball course, which covers the core basics of working with Unity: GameObjects, Components, Prefabs, Physics, and Scripting. The player controls a ball, collects pickups, and tries to reach the goal.

## Built With

- [Unity](https://unity.com/)
- C#
